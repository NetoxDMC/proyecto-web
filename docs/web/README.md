# Documentación web

Este directorio guarda las decisiones del proyecto para que todos los agentes trabajen con el mismo contexto.

## Orden de lectura

1. `brief.md`: qué se quiere conseguir y para quién.
2. `plan.md`: fases, responsables y estado.
3. `architecture.md`: sitemap, stack, estructura y riesgos.
4. `design.md`: dirección visual y sistema de diseño.
5. `copy.md`: textos, CTAs y metadatos.
6. `qa.md`: pruebas, hallazgos y evidencias.
