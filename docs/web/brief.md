# Brief — Nébula Café (demo ficticia)

## Objetivo

Crear una landing atractiva para una cafetería ficticia de especialidad en València, con el objetivo de probar el flujo completo: brief, diseño, copy, implementación, QA y despliegue en GitHub Pages.

## Audiencia

Personas de 25 a 45 años que viven o visitan el centro de València, buscan brunch de calidad, café de especialidad y un espacio tranquilo para quedar o trabajar un rato.

## Oferta / propuesta de valor

Café de origen, brunch de temporada y repostería artesanal en un espacio luminoso y sin prisa. La experiencia importa tanto como el producto.

## Páginas

| Página | Objetivo | Contenido |
| --- | --- | --- |
| Inicio | Presentar la cafetería y generar visitas o reservas | Hero, carta destacada, historia, reseñas, ubicación y horario |

## Contenido disponible

- Textos: ficticios, creados para la demo.
- Imágenes: ilustración vectorial propia; sin fotos externas.
- Logos: wordmark y favicon ficticios de Nébula.
- Testimonios: ficticios, marcados como tales.
- Datos de contacto: dirección y email ficticios (`.test`).

## Marca y referencias

- Personalidad: cálida, editorial, cercana y tranquila.
- Colores: crema, papel, marrón espresso, coral y verde salvia.
- Tipografía: serif editorial para titulares y sans geométrica para interfaz.
- Referencias: cafeterías de especialidad, revistas de food y diseño editorial.
- Evitar: estética corporativa fría, exceso de elementos, promesas reales.

## Stack

- Astro 7 + Tailwind CSS 4.
- Playwright para E2E.
- GitHub Pages para publicación.
- Sin backend: el sitio es estático.

## Integraciones

- Formularios: no hay; el CTA abre el cliente de email.
- Analítica: no configurada.
- CMS: no.
- Pagos: no.
- Email: enlace `mailto:` ficticio.

## Criterios de éxito

- Landing responsive y accesible.
- Navegación clara y CTA visible.
- Buen rendimiento sin JavaScript innecesario.
- Build, tests y despliegue automático correctos.

## Restricciones

- Negocio, dirección, email y reseñas son ficticios.
- Sin imágenes externas ni fuentes de terceros.
- Una sola página.
- Sin backend, auth ni pagos.
